A fork of the 桃の缶詰 ─ 手書きのテスト painting tool tweaked for use on αimg.

> ふたばの画像掲示板が標準で持つお絵かき機能よりちょっとできることが増えた版です。Chrome と Firefox で動作を確認しています。
> 
> ## 特徴
> 
> - 3枚までのレイヤー
> - 描線の補正、補間
> - 直線の描画
> - キャンバスの反転、回転
> - キャンバスのサイズ変更
> - キャンバスの表示を拡大、回転
> - アンドゥ、リドゥ
> - Ctrlクリックによるスポイト
> - Shift押下によるペン←→消しゴム切り替え
> - ホイールの回転によるペン幅変更、拡大率変更
> - スレッドが落ちていたときのためのキャンバスの持ち越し
> - 同一色領域の塗りつぶし
>
